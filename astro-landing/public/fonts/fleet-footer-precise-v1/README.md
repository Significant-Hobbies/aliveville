# Footer fonts

Exact OFL-licensed local Geist, Geist Mono and Newsreader WOFF2 assets from the owner-selected Precise study. Source URLs, real axes, hashes and license filenames are in provenance.json. The three OFL files accompany their fonts. No subsetting or renaming of font binaries; Fleet family names are CSS aliases only. Serve with font/woff2 and cross-origin CORS access for shared footer consumers. No Google Fonts request is made by the runtime.
